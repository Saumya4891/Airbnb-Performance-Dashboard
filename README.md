1. PROJECT TITLE: Global Airbnb Performance Dashboard

2. SHORT DESCRIPTION & PURPOSE 
The "Why": Airbnb generates massive amounts of data, but raw numbers don't tell a story. I built this dashboard to transform 5.3 million+ reviews and 279k+ listings into actionable business intelligence.
The Goal: To analyze market saturation, pricing strategies, and customer trust metrics across 10 major global cities. This tool helps stakeholders identify which cities are peaking, where pricing is competitive, and how host verification impacts customer trust.

4. TECH STACK 🛠️
Power BI Desktop: For robust data modeling and interactive visualization.
DAX (Data Analysis Expressions): Used to calculate dynamic KPIs like Cumulative Market Share %, Average Pricing, and Review Frequency.
Power Query: For ETL (Extract, Transform, Load) processes—cleaning dates and unpivoting city columns.
Maven Analytics: Utilized the Maven Airbnb dataset for this portfolio project.

4. DATA SOURCE 📊
Source: Maven Analytics Data Playground.
Scope: A comprehensive dataset covering 10 global cities (Paris, NYC, Sydney, Rome, etc.), including 279,712 listings, 144 property types, and over 5.3 million reviews.

5. FEATURES & HIGHLIGHTS ✨
I designed this dashboard with a user-centric approach, breaking it down into three logical views:

📈 Market Trends & Lifecycle:
Visualized the "Introduction to COVID-19" lifecycle of new listings.
Insight: Identified the 2015 "Peak Point" and the subsequent impact of local regulations and the pandemic on supply.
🏙️ Competitive Market Share:
    Built a Pareto Analysis showing that Paris, NYC, and Sydney account for nearly 50% of all reviews.
    Feature: A dynamic "Price War" chart comparing Airbnb prices against local hotel room rates (highlighting Paris as the most expensive market).
 Trust & Ratings Analysis:
Implemented a Heat Map to score cities on cleanliness, value, and accuracy.
Key Metric: Created a "Trust Shield" visual proving that 66.9% of hosts are fully verified, effectively reducing anonymous profiles to a minimal 0.3%.
